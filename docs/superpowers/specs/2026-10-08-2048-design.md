# Spec: 2048

**Category:** games
**Date:** 2026-10-08
**Issue:** #128

## Function

Classic 2048 sliding-tile puzzle on a 4×4 grid. Each move slides every tile as far as possible in one direction; two equal tiles that collide merge into their sum, and the merged value is added to the score. After every move that changes the board, a new tile (2 or 4) appears in a random empty cell. Reaching a 2048 tile shows a win dialog with the option to keep going; the game ends when the board is full and no merge is possible.

## Inputs

| Input | Type | Validation |
|---|---|---|
| Arrow key press (desktop) | `KeyboardEvent` | Only `ArrowUp/Down/Left/Right` handled; `preventDefault` stops page scroll; ignored unless `status === 'playing'` |
| Swipe gesture (mobile) | `TouchEvent` (`touchstart`/`touchend`) | Same as Snake: deltas under `SWIPE_THRESHOLD_PX = 20` ignored; direction from the larger of dx/dy; grid has `touch-none` so the page does not scroll |
| Random | `() => number` in `[0, 1)` | Injected into `newGame` and `move` — never called directly inside `logic.ts` |

---

## Outputs

| Output | Description |
|---|---|
| Board | 4×4 grid of tiles; empty cells shown as blank slots |
| Score | Sum of all merged tile values in the current game |
| Best | Highest score across sessions, persisted in `localStorage` |
| Win dialog | Shown the first time a 2048 tile appears: "Keep going" / "New game" |
| Game-over dialog | Final score, "new best" flag, "New game" |

## Logic / Algorithm

### Data Model

```ts
type Direction = 'up' | 'down' | 'left' | 'right'
type Status = 'playing' | 'won' | 'over'
type Board = number[][] // 4×4, row-major, 0 = empty

interface Position {
  row: number
  col: number
}

interface GameState {
  board: Board
  score: number
  status: Status
  keepPlaying: boolean   // true once the player chose "Keep going"
  spawned: Position | null // tile spawned by the last move (pop animation)
  merged: Position[]     // cells produced by a merge in the last move (pulse animation)
}
```

Constants: `BOARD_SIZE = 4`, `WIN_TILE = 2048`, `FOUR_PROBABILITY = 0.1`.

### `slideRow(row: number[]): { row: number[]; gained: number; mergedAt: number[] }`

Slides one row towards index 0:

1. Drop zeros: `[2, 0, 2, 4]` → `[2, 2, 4]`.
2. Walk left to right; when two adjacent values are equal, emit their sum, add it to `gained`, record the output index in `mergedAt`, and skip both. Each tile merges at most once per move.
3. Pad with zeros to length 4.

Examples: `[2,2,2,2]` → `[4,4,0,0]` (gained 8); `[4,4,8,0]` → `[8,8,0,0]` (gained 8, not `[16,0,0,0]`); `[2,4,8,16]` → unchanged.

### Directions

All four directions reuse `slideRow` by transforming the board, sliding each row left, and transforming back:

| Direction | Transform before / after |
|---|---|
| left | none |
| right | reverse each row |
| up | transpose |
| down | transpose, then reverse each row (inverse: reverse, then transpose) |

`mergedAt` indices are mapped back through the same inverse transform to board `Position`s.

### `spawnTile(board, rng): { board; position } | null`

- Collect empty cells in row-major order; if none, return `null`.
- Cell: `empty[Math.floor(rng() * empty.length)]`.
- Value: `rng() < FOUR_PROBABILITY ? 4 : 2` (90% 2, 10% 4).
- `rng` is called exactly twice per spawn: cell first, then value.

### `newGame(rng): GameState`

Empty board, two `spawnTile` calls, `score: 0`, `status: 'playing'`, `keepPlaying: false`, `spawned: null`, `merged: []`.

### `move(state, direction, rng): GameState`

1. If `status !== 'playing'`, return `state` unchanged.
2. Slide the board. If the board is identical to before (nothing moved or merged), return `state` unchanged — no spawn, no score change.
3. Add `gained` to `score`; set `merged`; spawn one tile and set `spawned`.
4. If any tile ≥ `WIN_TILE` and `!keepPlaying` → `status: 'won'`.
5. Else if `!canMove(board)` → `status: 'over'`.

### `canMove(board): boolean`

`true` if any cell is 0 or any two horizontally/vertically adjacent cells are equal.

### `keepGoing(state): GameState`

From `'won'`: `status: 'playing'`, `keepPlaying: true`. If the board has no moves left, `status: 'over'` instead. Any other status: unchanged.

## UI

- `'use client'` component; state in `useState<GameState>`, initialised with `newGame(Math.random)` after mount (avoids hydration mismatch).
- Header row: Score, Best, "New game" button.
- Board: square grid, full width on mobile, `max-w-md` on desktop, `aspect-square`, `touch-none select-none`.
- Tile colours: one Tailwind class set per value (2 … 2048), a single shared style for values above 2048; font size steps down for 3-, 4- and 5-digit values.
- Pop animation: the `spawned` cell gets a scale-in keyframe; `merged` cells get a short pulse. Keyframes defined via Tailwind `@theme` / `globals.css` animation utilities; both respect `motion-reduce`.
- Best score: `createHighScoreStore('2048:high-score')`; saved whenever `score` exceeds the stored best (keep-going games can be left at any time).
- Dialogs (shadcn `Dialog`, same pattern as Snake): win (`status === 'won'`) and game over (`status === 'over'`).
- User-facing strings in `messages.ts`.

---

## Edge Cases

- Move that changes nothing → no spawn, no score change, state object returned as-is.
- `[2,2,2,2]` merges into two 4s, never one 8.
- `[4,4,8,0]` → `[8,8,0,0]`: a freshly merged tile does not merge again in the same move.
- 2048 reached and the board is also full with no moves → `status: 'won'` first; "Keep going" then lands in `'over'`.
- Tiles above 2048 (4096, 8192, …) render with the shared "super tile" style.
- Moves ignored while a dialog is open (`status !== 'playing'`).
- Swipes shorter than the threshold are ignored (taps do nothing).

## Tests

### Unit (`logic.test.ts`)

- `slideRow`: empty row, no-op row, gaps, single merge, `[2,2,2,2]`, `[4,4,8,0]`, gained points, `mergedAt` indices.
- `move` in all four directions on a known board, including merged positions mapped back correctly.
- No spawn and identical state when a move changes nothing.
- `spawnTile`: picks the cell from the first `rng` call; second `rng` call `< 0.1` gives 4, otherwise 2; `null` on a full board.
- `newGame`: exactly two tiles, score 0.
- Score accumulates across moves.
- Win on first 2048; no second win after `keepGoing`; `keepGoing` → `'over'` when stuck.
- Game over on a full board with no equal neighbours; not over when a merge is still possible.

### E2E (`tests/e2e/2048.spec.ts`)

- Page loads with title, score 0 and two tiles.
- Pressing all four arrow keys produces at least three tiles (at least one move must change a two-tile board) and the board is still rendered.
- Screenshot of the default state for visual review.
